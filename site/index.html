프롬프트 만들기 2차시

좋은 프롬프트는 역할 + 목적 + 대상 + 기능 + 디자인이에요. 목적·대상·기능·디자인은 1차시 기획서에서 자동으로 가져와요. 역할과 추가 요구사항만 채우면 돼요.

나쁜 예
"과학 게임 만들어줘"
→ 무슨 과학? 누가? 어떻게? 알 수 없어요.
좋은 예
"너는 웹 개발자야. 중학생이 원소 기호를 외우도록 돕는 카드 짝 맞추기 게임을 HTML 한 파일로 만들어줘. 점수와 타이머가 있고, 밝고 귀여운 디자인으로."
